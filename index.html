What this build adds

  • System Monitor — total and per-process CPU, memory, user and Windows service, plus temperatures where the computer reports them.
  • Process Intelligence Report — for any running program: its digital signature, privileges, open sensitive files, camera and microphone use, injected code, network destinations and listening ports, with a risk rating.
  • Force block per app — block or unblock internet access for a program straight from its report.
  • Firewall Profiles — apply a ready-made set of firewall settings, preview the changes first, and undo them later.
  • Quick block buttons — block all internet or local network connections with one click.

Installing

Windows

  1. Download and run the installer. It needs administrator rights, because Portmaster installs a network driver.
  2. The installer is not code-signed, so Windows SmartScreen says “Windows protected your PC”. Choose More info, then Run anyway.
  3. To check the file, compare its SHA-256 (PowerShell: Get-FileHash .\Portmaster-band72-windows-x64-setup.exe) with the value shown above.

Linux

  1. Download the package for your distribution, then install it from the folder you saved it to: 
    sudo apt install ./Portmaster-band72-linux-amd64.deb
    sudo dnf install ./Portmaster-band72-linux-x86_64.rpm
  2. Restart the computer. Portmaster runs as the portmaster system service and starts its window when you log in.
  3. To check the file, compare sha256sum Portmaster-band72-linux-* with the value shown above.
  4. To remove it: sudo apt remove portmaster or sudo dnf remove portmaster.

Updates

Automatic software updates are off in this build, because Portmaster's updates come from Safing's official channel and would replace this build with the official version. Come back to this page for new versions. Filter lists and other intelligence data still update automatically.

Do not use Check for updates in the Portmaster settings: it installs the official version. If you installed over an official Portmaster where you had turned automatic updates on yourself, turn them off under Settings › Updates.
